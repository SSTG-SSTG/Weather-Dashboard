# Weather-Dashboard
# 🌦️ Weather Dashboard  A responsive web app built with HTML, CSS, &amp; Vanilla JS using OpenWeatherMap API.  ## ✨ Features - 🔍 Live city weather search - 🌡️ Temp, Humidity &amp; Wind speed - ⏳ Loading &amp; Error handling - 📱 Mobile-friendly layout  ## 🛠️ Tech HTML5 | CSS3 | JavaScript (Async/Await, Fetch API)
